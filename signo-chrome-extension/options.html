Compatibility

Types like a real keyboard, so it works on every website, including Google Docs, online editors, chat apps and embedded frames. Turn off to use basic typing, which only works in ordinary text boxes.

Universal typing uses Chrome's built-in debugger to send keystrokes. While Sign-O types, Chrome shows a “Sign-O started debugging this browser” bar. That is expected and only means Sign-O can type into the page. No extension can type on chrome:// pages, the new-tab page or the Chrome Web Store.
